# Phase 6 MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add stdio MCP server and client support so this project can expose local tools and consume external MCP tools.

**Architecture:** Add a dedicated `app/services/mcp/` package for adapter, server, client, and runtime code. Keep `ToolRegistry` behavior backward-compatible and attach MCP tools only when a runtime is present. Add debug API endpoints and script entry points without changing LLM provider flow.

**Tech Stack:** Python 3.11, FastAPI, httpx, pytest, official `mcp` Python SDK.

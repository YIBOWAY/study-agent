# Citation Rules for Capstone

1. Prefer exact quotes that appear in local `Source.content`.
2. Every claim must reference at least one evidence ID.
3. Every evidence item must reference an existing source ID.
4. Link records must expose claim text, quote, source title, and source URI.
5. Ranking from `FakeRetriever` is not evidence by itself.
6. Unsupported claims are defects, not style preferences.
7. Keep Capstone offline: no live search APIs and no invented paper URIs.

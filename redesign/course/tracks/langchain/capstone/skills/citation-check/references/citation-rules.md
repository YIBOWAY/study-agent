# Citation Rules for LC Capstone

1. Prefer exact quotes that appear in local `PaperDoc.content`.
2. Every claim must reference at least one evidence ID.
3. Every evidence item must reference an existing paper / source ID.
4. Link records must expose claim, quote, source title, and source URI.
5. Ranking from `BaseRetriever` is not evidence by itself.
6. Unsupported claims are defects, not style preferences.
7. Keep Capstone offline for unit gate: no live search APIs and no invented paper URIs.
